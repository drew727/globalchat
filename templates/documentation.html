Docs / API / Reconciliation

API Specification

Submit a POST request to the state reconciliation endpoint with a valid X-SNS-NODE-KEY header.

curl -X POST https://systemnodesync.dpdns.org \
  -H "Content-Type: application/json" \
  -H "X-SNS-NODE-KEY: [REDACTED]" \
  -d '{"state": "sync"}'
